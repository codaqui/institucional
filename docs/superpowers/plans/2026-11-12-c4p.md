# C4P (Chamada de Trabalhos) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar o subsistema C4P completo (backend NestJS 1.0.0 + migration 049 + frontend Astro + snapshot + e-mails + PDF), fechando a Fase 7 do plano 1.0.0 e a ADR 012.

**Architecture:** Módulo NestJS `c4p/` com 3 tabelas novas (`c4p_calls`, `c4p_talks`, `c4p_votes`) + índice único parcial em `member_designations`; avaliadores são designations (`evaluator @ c4p_campaign`), não tabela própria. Submissão pública com Turnstile (ação nova `c4p_submission`) e consentimento LGPD. Snapshot público `static/c4p/index.json` gerado por sync workflow (pattern events/announcements). Frontend: páginas públicas estáticas geradas do snapshot + ilhas React/MUI para submissão, votação e gestão; PDF do relatório no cliente (jspdf + jspdf-autotable).

**Tech Stack:** NestJS 11 + TypeORM 0.3 + PostgreSQL, class-validator, jest; Astro 7 + React 19 + MUI v9 + vitest; scripts `.mjs` com `node --test`.

**Spec:** `docs/superpowers/specs/2026-11-12-c4p-design.md` (contrato completo — shapes de API, regras e decisões estão lá; este plano não os repete, só os referencia).

## Global Constraints

- **PROIBIDO** portar PII ou senhas do sistema externo (`code-to-analyze/`); testes usam dados sintéticos (spec, "Segurança e LGPD").
- APIs de gestão **não** usam prefixo `/admin/`; proxy recebe apenas `/c4p/public/`, `/c4p/manage/`, `/c4p/evaluator/` + exceção exata `/c4p/index.json`.
- Notas e comentários de avaliação **nunca** aparecem em snapshot, vitrine ou resultado (whitelist de campos).
- Finalizar/reabrir campanha é **somente `admin`** (rbac.md venceu o anexo — spec, decisão 1).
- Bump de `backend/package.json` → **1.0.0** na Task 16 (feat/major do marco 1.0.0).
- Commits: `feat(c4p): …` / `test(c4p): …` / `docs(c4p): …`, convencional, em português como o histórico recente.
- Backend: `cd backend && npx jest <padrão>` para teste focado; `npm run build && npx jest --silent` para gate.
- Frontend: `cd frontend && npx vitest run <arquivo>`; gate `npm run build && npm run check && npm run test`.
- Scripts: `npm run test:scripts` (raiz, `node --test scripts/*.test.mjs`).
- MUI v9: named imports, `sx`, `slotProps`; **zero hex** fora de tokens; ilhas usam `resolveApiUrl(import.meta.env.SITE)`.
- Paginação: envelope `PaginatedResultDto` (`{data,total,page,totalPages,limit}`) no backend; `PaginationControls` + `DEFAULT_PAGE_SIZE`/`rangeLabel` no frontend.

## Review Focus

1. **Voto com critérios parcialmente preenchidos** — o peso entra só para os critérios votados (`Σ score×peso / Σ peso dos presentes`); testado na Task 3 (scoring) e Task 11 (guards de votos).
2. **CSV do Google Forms com delimitador `;` e cabeçalhos fora da lista** — linhas sem nome/título ou com e-mail inválido vão para `skipped` sem quebrar o lote; testado nas Tasks 2 e 9.
3. **Slug reservado (`public`/`manage`/`evaluator`/`avaliar`) colidindo com proxy ou rotas de app** — rejeitado na criação; testado na Task 7 e nos testes de proxy da Task 17.
4. **Avaliador removido ou com campanha `closed` tentando votar** — 403/409, e votos antigos do removido continuam contando na média; testado nas Tasks 11 e 13.
5. **Resultado público vazando notas/comentários** — snapshot e endpoint de resultado só expõem `{title, speakerName, track, level}` das selecionadas; testado nas Tasks 12 (shape) e 14 (controllers).
